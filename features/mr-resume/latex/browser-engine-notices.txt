SmilePDF MR Resume browser-local compiler notices
================================================

The host-facing browserEngine.ts IPC adapter is independently authored. It does
not import SwiftLaTeX's optional client API classes. Compiler code is downloaded
directly from upstream, SHA-256 verified, and run in disposable worker contexts.
The existing native backend is a separate execution route, not certified by this
browser implementation. This notice does not change the host application's
license or promise that every possible combined distribution is exempt from
third-party copyleft obligations.

TeX Live public format and dependencies
--------------------------------------
The free endpoint https://texlive.texlyre.org/ serves TeX Live 2020 files.
The matching swiftlatexxetex.fmt is SHA-256 pinned by the adapter. Other requested
packages/fonts are fetched on demand and keep their individual upstream
licenses. Source/copyright information: https://www.tug.org/texlive/copying.html
and the individual package sources at https://ctan.org/ . No uniform permissive
license is claimed for these files. The public service is not a paid cloud
compiler: only dependency GET requests leave the worker, never source bodies.
Requested package, font or missing-asset basenames may be visible to the service.

Compiler code and dependencies are provided under their upstream licenses,
without warranty. Browser output is not native/gVisor-certified. Biber, LuaLaTeX
and SyncTeX are not supported by this SwiftLaTeX execution route.
