The BusyTeX wrapper is MIT-licensed (licenses/busytex-notices.txt). The statically linked TeX engine binary includes GPL/LGPL and other separately licensed components; it is NOT an MIT-only binary. The binary's archived upstream engine/library sources and build recipe are offered by equivalent same-origin access in source-offer.json and sources/. Original component notices extracted from those archives remain in licenses/. This separate vendor distribution does not change the surrounding application's licensing. No AGPL wrapper or BusytexPipeline is included.

The six real groups are core, pdflatex, xelatex, lualatex, unicode and math. Only math is an optional package group; tcolorbox/mdframed are test fixtures, not deployed packages. All groups are a disjoint partition of the unchanged legacy snapshot; per-file source paths, sizes and hashes remain in snapshot-index.json and each group index. TeX package source files from the basic archive remain in sources/tex-packages-source.tar.gz. Exact supplemental runtime TeX/Lua/config/map files and original embedded license evidence are in sources/tex-supplemental-runtime-source.tar.gz and its index. These raw shipped files are not a complete upstream .dtx/.ins/documentation archive. The pinned BusyTeX recipe selects full TeX Live files using historical Ubuntu Lunar file lists; package naming is not proof of .deb byte provenance. Original input URLs, known hashes and unavailable source-input limits are recorded honestly in the supplemental index.

Original package copyright/license headers remain unmodified; no group receives a blanket MIT/LPPL label. LICENSE.TL and LICENSE.CTAN explain per-component licensing. Latin Modern uses the GUST Font License; Computer Modern/AMS retain their own original notices. Noto Sans Bengali is unmodified, Copyright 2022 The Noto Project Authors, SIL OFL 1.1, pinned google/fonts commit e7db6ca603fd4862010383ff17ffd6cc4ffac1c0. Full upstream generated-package/font-development source completeness is not claimed by the raw runtime source offer.

Provisioning source includes the exact Latin Modern license input and deployed worker. Its archived smoke scripts depend on application TS/npm/template inputs and are not standalone. --manifest/--groups regenerate local assets without downloading or running TeX; real-engine smoke/corpus verification is a separate future release prerequisite. Runtime asset GETs are same-origin and selected from exact pins; worker network APIs are shut down before TeX execution. The shared global CSP has no connect-src endpoint hard-list and is not changed by this module. Source, filenames and PDFs are never uploaded by local compilation; source/license archives are not loaded by the compiler. Shell escape, sockets, remote package loading and native filesystems are disabled.
